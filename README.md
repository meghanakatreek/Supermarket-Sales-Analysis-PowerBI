🛒 Supermarket Sales Analysis – Power BI

📊 Project Overview

This project analyzes supermarket sales data using Microsoft Power BI.

The dashboard provides insights into sales performance, product sales,
customer ratings, payment methods, and revenue trends.

 🎯 Objectives

- Analyze total revenue
- Analyze branch performance
- Identify top-performing product lines
- Analyze customer ratings
- Understand payment method usage
- Analyze daily and monthly revenue
- Track total quantity sold
- Analyze gross income

🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Microsoft Excel / CSV
- Data Visualization
- Data Analysis

📌 Key KPIs

- Total Revenue
- Total Quantity
- Total Transactions
- Average Customer Rating
- Total Gross Income
